# Internet Auction - Web UI

Простий веб-інтерфейс для пошуку й фільтрації лотів аукціону.

## Як запустити

### Требування
- .NET 9.0+
- SQL Server (або Docker для SQL Server контейнера)

### Запуск приложення

1. **Запустити SQL Server через Docker** (опціонально, якщо потрібно):
   ```bash
   docker-compose up -d
   ```

2. **Запустити WebAPI**:
   ```bash
   cd PL
   dotnet run
   ```

3. **Відкрити UI в браузері**:
   - Основний UI: `https://localhost:5001` (або `http://localhost:5184`)
   - Swagger API документація: `https://localhost:5001/swagger`

## Функціонал

### Пошук лотів
- **За назвою** — введи текст для пошуку по назві й описанню лота
- **За ціною** — встави мінімальну й максимальну стартову ціну
- **За статусом** — фільтруй за статусом (Активні, Очікує підтвердження, тощо)
- **За категорією** — вибери категорію з dropdown

### Результати
- **Картки лотів** — кожна картка показує основну інформацію
- **Детальний перегляд** — натисни на картку, щоб побачити повну інформацію в модальному вікні
- **Динамічна фільтрація** — результати оновлюються при кожному натисканні "Пошук"

## Технічні деталі

### API Запити
UI формує REST API запити до WebAPI:

```
GET /api/lots/search?searchQuery=iPhone&minPrice=100&maxPrice=500&categoryId=1&status=Active
```

### Параметри
- `searchQuery` (optional) — текст для пошуку по назві/опису
- `minPrice` (optional) — мінімальна ціна
- `maxPrice` (optional) — максимальна ціна
- `categoryId` (optional) — ID категорії
- `status` (optional) — статус лота (Pending, Active, Sold, NotSold, Cancelled)

### JavaScript Features
- **Async/Await** — сучасний спосіб роботи з AJAX
- **DOM Manipulation** — динамічне добавління елементів
- **URL Parameters** — безпечна передача параметрів запиту
- **Error Handling** — обробка помилок з виводом повідомлень
- **HTML Escaping** — захист від XSS атак

## Дизайн

- **Gradient Background** — сучасний фіолетовий градієнт
- **Responsive Grid** — адаптивна сітка для карток (автоматично перелаштовується на мобільних)
- **Modal Window** — для детальної інформації про лот
- **Status Badges** — кольорові значки для статусів

## Альтернативні способи тестування

Якщо UI не потрібен, можна тестувати через:

1. **Swagger UI** — вбудована документація WebAPI
   - Відкрий: `https://localhost:5001/swagger`
   - Натисни "Try it out" на будь-якому ендпоінті

2. **curl** — команди для терміналу
   ```bash
   curl 'http://localhost:5184/api/lots/search?searchQuery=iPhone'
   ```

3. **Postman** — натяжна програма для тестування API
   - Імпортуй Swagger схему або вручну додай запити

## Розробка

Щоб змінити UI:

1. Редагуй HTML в `index.html`
2. Змінюй стилі в `css/style.css`
3. Оновлюй логіку в `js/app.js`
4. Оновлення видиме без перезапуску сервера (лише оновіть браузер)
